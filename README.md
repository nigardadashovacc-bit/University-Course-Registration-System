# University-Course-Registration-System
University Course Registration System

A Python-based course registration system developed as part of my AI Engineering training at IDTECH Academy.

Project Description

This project simulates a university course registration system using Object-Oriented Programming (OOP) principles.

Features

* Student, Teacher, and Course classes
* Course enrollment and withdrawal
* Automatic waitlist management
* Prerequisite validation
* Grade recording and GPA calculation
* Custom exception handling

Technologies

* Python 3
* Object-Oriented Programming (OOP)

How to Run

1. Download the Python file.
2. Open it in VS Code or PyCharm.
3. Run python university_course_registration_system.py.

What I Learned

Through this project, I practiced Python programming, class relationships, encapsulation, exception handling, and implementing real-world registration logic.
